About AppGraph

AppGraph is a web application that provides a visual representation of the relationships between applications, projects, and environments. It allows users to easily understand how different components of their software ecosystem are connected and interact with each other.

AppGraph is built using Spring Boot and Neo4j, leveraging the power of graph databases to model complex relationships. The application provides a user-friendly interface for exploring and managing these relationships, making it easier for developers and project managers to gain insights into their software architecture.
